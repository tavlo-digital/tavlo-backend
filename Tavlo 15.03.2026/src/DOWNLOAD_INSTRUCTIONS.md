## Download Methods:

### Method 1: Individual File Download
- Click each file in the left sidebar
- Right-click → "Save As..." or use the download button
- Save with `.md` extension

### Method 2: Copy-Paste
1. Open each file
2. Select All (Ctrl+A / Cmd+A)
3. Copy (Ctrl+C / Cmd+C)
4. Paste into local text editor
5. Save as `.md` file

### Method 3: Export Project
- Look for "Export" or "Download Project" option
- This downloads all files at once

## Troubleshooting:

### If download fails:
1. **File too large:** Use copy-paste method instead
2. **Browser issue:** Try different browser (Chrome, Firefox, Safari)
3. **Format issue:** Make sure to save with `.md` extension

### If you need a different format:
- **PDF:** Use a Markdown viewer (Typora, VS Code) and export to PDF
- **Word:** Import `.md` files into Word or Google Docs
- **HTML:** Use a Markdown converter (Pandoc, online tools)
